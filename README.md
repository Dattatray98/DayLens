# Daylens

**See your life more clearly.**

Your personal space for money, nutrition, wellness, notes, and insights. Daylens keeps your workspace on this device using local SQLite with browser persistence.

## Development

```sh
npm run dev
```

## Production build

```sh
npm run build
```

The application uses React, TypeScript, Vite, Tailwind CSS, React Router, and SQLite. It has no application backend or cloud account service.
